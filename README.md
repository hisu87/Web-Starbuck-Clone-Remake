## ✨ Tính năng nổi bật

- 🎨 **Giao diện giống Starbucks** – thiết kế hiện đại, chuyên nghiệp
- 📱 **Responsive** – hiển thị đẹp trên mọi thiết bị
- 🖱️ **Hiệu ứng động mượt mà** với CSS & JavaScript
- 📋 **Menu, banner, sản phẩm, footer** đầy đủ
- 🚀 **Tối ưu mã nguồn** – dễ dàng mở rộng, chỉnh sửa

---

## ✨ Main Features

- 🎨 **Starbucks-like interface** – modern and professional layout
- 📱 **Responsive** – optimized for all devices
- 🖱️ **Smooth CSS & JS animations**
- 📋 **Full menu, banners, product sections, and footer**
- 🚀 **Clean, maintainable code** – easy to expand or customize
